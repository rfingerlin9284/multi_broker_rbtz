STRATEGY-SPECIFIC STOP CONFIGURATIONS
--------------------------------------

1. FABIO_AAA_FULL (Volatility-Adaptive Multi-Tranche)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Style: Aggressive attention-intensive
   Stop Type: Dynamic volatility-based
   
   Config Variables:
   - FABIO_STOP_MIN_PCT=0.01      (1% minimum)
   - FABIO_STOP_MAX_PCT=0.08      (8% maximum)
   - FABIO_STOP_VOL_MULT=3.0      (3x local volatility)
   
   Logic:
   - Calculates local volatility using range bars
   - Stop = volatility * multiplier
   - Clamped between min/max bounds
   - Tranche-based partial stops for staged exits
   
   Why: High-frequency momentum requires tight initial stops with
        room for volatility expansion. Tranches lock profits.

2. HOLY_GRAIL (Wide Momentum)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Style: Data-driven momentum (avoids 95% stop-out rate)
   Stop Type: Fixed percentage
   
   Config Variable:
   - HOLY_GRAIL_STOP_PCT=0.03     (3% stop)
   
   Logic:
   - Buy: stop = entry * (1 - 3%)
   - Sell: stop = entry * (1 + 3%)
   
   Why: Old strategy had 95% stop-out rate with tight SMA stops.
        Wide 3% stop gives momentum room to develop while
        RSI/volume filters ensure quality entries.

3. EMA_SCALPER (Tight Crossover)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Style: Fast EMA crossover scalping
   Stop Type: Tight fixed percentage
   
   Config Variable:
   - EMA_SCALPER_STOP_PCT=0.005   (0.5% stop)
   
   Logic:
   - Buy: stop = entry * (1 - 0.5%)
   - Sell: stop = entry * (1 + 0.5%)
   
   Why: Scalping requires immediate stops to limit loss on
        false signals. Quick in/out with tight risk.

4. INSTITUTIONAL_SD (Volatility Breakout)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Style: Standard deviation expansion momentum
   Stop Type: Conservative fixed percentage
   
   Config Variable:
   - INST_SD_STOP_PCT=0.01        (1% stop)
   
   Logic:
   - Buy: stop = entry * (1 - 1%)
   - Sell: stop = entry * (1 + 1%)
   
   Why: Volatility breakouts can whipsaw. 1% stop protects
        against false breakouts while allowing trend capture.

5. TRAP_REVERSAL (Mean Reversion)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Style: Spike reversal mean reversion
   Stop Type: Dynamic beyond spike extreme
   
   Config Variable:
   - TRAP_REVERSAL_STOP_MULT=0.5  (0.5x spike size)
   
   Logic:
   - Stop = spike_extreme + (spike_size * 0.5)
   - Adaptive to spike magnitude
   
   Why: Mean reversion bets on spike exhaustion. Stop beyond
        spike extreme invalidates thesis if trend continues.

PLATFORM-SPECIFIC CONSIDERATIONS
---------------------------------

OANDA (Forex):
- Typical pip values: 0.0001 (0.01%)
- Recommended: HOLY_GRAIL, INST_SD (wider stops for FX volatility)
- Avoid: EMA_SCALPER (too tight for spreads)

COINBASE (Crypto):
- Higher volatility: 2-5% daily swings
- Recommended: FABIO_AAA_FULL (adaptive), HOLY_GRAIL (wide)
- Avoid: EMA_SCALPER (crypto gaps too large)

IBKR (Futures):
- Leverage amplifies stops
- Recommended: HOLY_GRAIL, INST_SD (controlled risk)
- Monitor: FABIO_AAA_FULL (max leverage with adaptive stops)

TUNING GUIDANCE
----------------

To Tighten Stops (reduce max loss per trade):
1. Lower FABIO_STOP_MAX_PCT (8% → 5%)
2. Lower HOLY_GRAIL_STOP_PCT (3% → 2%)
3. Risk: Higher stop-out rate

To Widen Stops (give trades more room):
1. Increase FABIO_STOP_MIN_PCT (1% → 1.5%)
2. Increase HOLY_GRAIL_STOP_PCT (3% → 4%)
3. Risk: Larger max loss per trade

To Make Stops More Adaptive:
1. Increase FABIO_STOP_VOL_MULT (3.0 → 4.0)
2. Adjust TRAP_REVERSAL_STOP_MULT (0.5 → 0.75)
3. Effect: Stops expand/contract with market conditions
