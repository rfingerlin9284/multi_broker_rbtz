### Position Time Limits
```
ACTIVE POSITIONS CHECKED EVERY 30 SECONDS

```

### Daily Drawdown Control
```
Daily Loss Tracking:
  0% - 2.0% → Normal operation
  2.0% - 3.0% → Reduce position size by 50%
  > 3.0% → Emergency stop, review trades
```

### Trailing Stops
```
All positions get trailing stops at:
  • 1.0x R:R: Tighten to break-even
  • 1.5x R:R: Tighten to +0.5R
  • 2.0x R:R: Tighten to +1.0R
```

### Partial Profit Taking
```
At each risk-reward level:
  • 0.5x R:R: Close 33% position
  • 1.0x R:R: Close 33% position
  • 1.5x R:R: Close 33% position (remaining runs)
```
