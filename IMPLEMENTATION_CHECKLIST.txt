VERIFICATION FLOW:

1. PLACEMENT (Broker Connector)
   Order → broker.place_order() → _pending_fills
   Count: _total_trades_today (includes placements)

2. VERIFICATION (Broker Connector)
   Query → broker.verify_order_filled(order_id) → API check
   If FILLED: _pending_fills → _filled_orders
   Count: _total_filled_orders (verified fills ONLY) ✅

3. RETRIEVAL (Client Code)
   filled_count = connector.get_filled_orders_count()
   Returns only VERIFIED filled orders, not placements

USAGE IN CODE:

# Standard placement and verification
connector = get_coinbase_connector()

# 1. Place order (goes to _pending_fills)
result = connector.place_live_order(candidate, size)
order_id = result['order_id']

# 2. Verify order filled (moves to _filled_orders if confirmed)
if connector.verify_order_filled(order_id):
    print(f"✅ Order {order_id} confirmed filled")

# 3. Report only verified fills
filled_count = connector.get_filled_orders_count()
print(f"Trades today: {filled_count} (verified fills only)")

# 4. Debug stuck orders
pending = connector._pending_fills
if len(pending) > 5:
    print(f"⚠️ {len(pending)} orders still pending")
